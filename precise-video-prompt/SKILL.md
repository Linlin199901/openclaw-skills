# 精准视频生成提示词转换技能

本技能提供严格的、标准化的剧本→视频提示词转换流程，确保生成的视频完全忠实于原始剧本和分镜，最大限度减少AI误解和错误生成。

## 核心原则

### 1. 完全忠实原则
- **不添加**：不添加剧本中没有的内容
- **不修改**：不修改剧本中的对话和动作
- **不创意**：不进行创意发挥，严格按原文转换
- **不简化**：不简化复杂场景，完整保留

### 2. 标准化结构原则（音视频一体）
使用严格的标准化结构，包含完整音频元素：
```
[场景：地点+时间+氛围] + [角色：外貌+位置] + [动作：主体+动作描述] + [镜头：运镜类型] + [对话：角色+声音属性+情绪+台词] + [环境音：类型+描述] + [音效：动作+材质+拟声词] + [音乐：类型+情绪+描述] + [特效：必要特效]
```

### 音频精确转换原则
1. **对话完整性**：保留所有台词，不删减不修改
2. **声音属性**：为每个角色指定明确的声音特征
3. **环境真实**：根据场景添加对应的环境音
4. **音效同步**：动作与音效精确对应
5. **情绪匹配**：音乐与画面情绪一致

### 3. 减少歧义原则
- 使用明确的标签和分隔符
- 避免模糊描述和代词
- 为每个元素提供完整上下文
- 保持时序逻辑清晰

5. 标记音频需求
6. 记录特效要求

## 错误减少策略

### 1. 明确角色标识
- **错误**：`[他]说...`
- **正确**：`[陈代码]说...`
- **规则**：始终使用角色全名或明确标签

### 2. 完整动作描述
- **错误**：`[走到]桌子前`
- **正确**：`[陈代码走到]桌子前`
- **规则**：动作必须包含执行主体

### 3. 避免模糊时间
- **错误**：`[过了一会儿]`
- **正确**：`[时间：3秒后]` 或使用具体描述
- **规则**：使用具体时间或连续动作描述

### 4. 清晰空间关系
- **错误**：`[在那边]`
- **正确**：`[在办公室的东南角]`
- **规则**：提供具体位置信息

### 5. 统一术语
- 建立并始终使用统一的术语表
- 避免同义词混用
- 保持描述一致性

## 故障排除

### 常见问题
1. **AI误解角色**：确保角色标签唯一且明确
2. **动作错位**：提供完整的空间和时间上下文
3. **时序混乱**：使用明确的时序标记
4. **特效缺失**：确保特效描述具体且完整
5. **音频不同步**：音效与动作帧不匹配
6. **对话不清晰**：背景音掩盖对话
7. **音乐情绪错位**：音乐与画面情绪不一致
8. **环境音不真实**：环境音与场景不符

### 解决方案
1. 增加角色外貌和位置描述
2. 添加动作前后的环境参考
3. 使用时间戳或连续动作描述
4. 提供特效的视觉参考描述
5. **音频同步**：使用精确时间描述，添加同步标签
6. **对话清晰**：降低背景音量，提高对话优先级
7. **音乐匹配**：明确指定音乐情绪和类型
8. **环境真实**：分层描述环境音，添加空间感

### 🎥 运镜提示词写作5条心法

> 来源：WaytoAGI · 小歪的AI工具箱 (2026-04-15)
> 完整参考：[运镜语言参考库](../references/camera-movement-reference.md)

1. **运镜指令放最前面**：AI对开头权重更高。先写运镜再描述场景
2. **写清起点终点**："从全景推近至眼部特写"，不是"推镜头拍脸"
3. **给速度词**：缓慢=深情/悬疑，快速=紧张/冲击，由慢到快=升温/高潮
4. **运镜+情绪黄金搭档**："缓慢推镜头，沉重压抑"胜过"推镜头"
5. **一条最多1-2种运镜**：15秒内1-2种够用，复杂拆多条后期拼接

### 网剧场景 × 运镜速查
| 场景 | 推荐运镜 | 情绪 |
|------|----------|------|
| 开场建立 | 鸟瞰俯拍/升降下降 | 壮阔、降临 |
| 对话冲突 | 固定/推镜头 | 紧张、对峙 |
| 情感爆发 | 希区柯克变焦/推镜头 | 震惊、崩溃 |
| 角色登场 | 垂直摇镜/环绕 | 仪式、酷炫 |
| 追逐打斗 | 跟随/快速甩镜 | 紧张、速度 |
| 离别场景 | 拉镜头/升降上升 | 孤独、升华 |
| 揭示真相 | 推镜头/希区柯克变焦 | 震撼、聚焦 |
| BSOD/故障 | 快速甩镜+推镜头 | 混乱、冲击 |

### 连接符号
- `+`：元素连接
- `，`：同一元素内的属性分隔
- `：`：标签与内容分隔
- `" "`：对话内容引号

### 时序控制
- 默认：按出现顺序
- 明确时序：`[时间：2秒后]` + `[动作：...]`
- 同时发生：`[同时]` + `[动作A]` + `[动作B]`
