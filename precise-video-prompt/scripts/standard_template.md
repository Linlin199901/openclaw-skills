# 标准化剧本模板

## 剧本编写规范

### 1. 场景描述格式
```
场景：[地点]，[时间]，[氛围]
示例：场景：现代办公室，夜晚，安静氛围
```

### 2. 角色描述格式
```
角色：[角色名]，[外貌特征]，[位置]
示例：角色：陈代码，25岁程序员打扮，坐在电脑前
```

### 3. 动作描述格式
```
[角色名][动作描述]
示例：陈代码快速敲击键盘
```

### 4. 对话描述格式
```
[角色名]说："[对话内容]"
示例：陈代码说："这个BUG太奇怪了。"
```

### 5. 镜头描述格式（分镜）
```
[镜头类型][拍摄目标]
示例：特写陈代码面部表情
```

### 6. 音频描述格式
```
[音频类型][描述]
示例：系统提示音响起
```

### 7. 特效描述格式
```
[特效类型][描述]
示例：电脑屏幕闪烁红光
```

## 错误示例与修正

### 错误示例1：模糊描述
```
错误：他走到那边
问题：角色不明确，位置模糊
修正：陈代码走到办公室的东南角
```

### 错误示例2：缺少主体
```
错误：快速敲击键盘
问题：不知道谁在敲键盘
修正：陈代码快速敲击键盘
```

### 错误示例3：时间模糊
```
错误：过了一会儿
问题：时间不明确
修正：3秒后，陈代码抬头
```

### 错误示例4：空间模糊
```
错误：在那边
问题：位置不具体
修正：在办公室的打印机旁边
```

### 错误示例5：代词混乱
```
错误：他看着她，她笑了
问题：多个"他/她"容易混淆
修正：陈代码看着苏清雪，苏清雪笑了
```

## 质量控制要点

### 转换前检查
1. **角色明确性**：每个角色都有唯一名称
2. **动作完整性**：每个动作都有明确主体
3. **时空清晰性**：场景、时间、位置明确
4. **对话准确性**：对话内容完整准确
5. **特效具体性**：特效描述具体可执行

### 转换中检查
1. **标签正确性**：使用正确的标准化标签
2. **结构完整性**：包含所有必要元素
3. **时序合理性**：动作和对话时序合理
4. **平台适配性**：添加平台优化标签

### 转换后检查
1. **可读性**：提示词易于理解
2. **可执行性**：AI能够准确执行
3. **忠实度**：完全忠实于原始剧本
4. **错误率**：预估错误生成概率低

## 批量处理模板

### 剧本文件命名
```
第1集_剧本.txt
第1集_分镜.txt
第2集_剧本.txt
第2集_分镜.txt
...
```

### 转换脚本使用
```bash
# 单集转换
python precise_convert.py 第1集_剧本.txt --platform jimeng

# 批量转换
for i in {1..10}; do
    python precise_convert.py "第${i}集_剧本.txt" --platform jimeng --output "第${i}集_即梦版.txt"
done
```

## 常见问题解决

### Q1：AI仍然误解角色怎么办？
A：增加角色外貌和位置描述，确保每个动作都明确指定角色。

### Q2：动作时序混乱怎么办？
A：使用明确的时间标记，如`[时间：2秒后]`或描述连续动作。

### Q3：特效效果不理想怎么办？
A：提供更具体的特效描述，包括颜色、强度、持续时间。

### Q4：平台适配不佳怎么办？
A：根据平台特点调整优化标签，参考平台官方文档。

### Q5：批量处理效率低怎么办？
A：使用脚本批量处理，建立标准化模板库。
