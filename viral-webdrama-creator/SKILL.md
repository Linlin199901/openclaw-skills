# Viral Webdrama Creator Skill (爆款网剧创作大师)

## 技能概述
这是一个专门针对抖音、红果等短视频平台的爆款网剧创作技能。基于最新的市场数据、平台算法和用户心理，提供从创意到分镜的完整解决方案。特别优化了前3秒留存率、完播率和互动率。

## 🎯 核心优势
- **数据驱动**：基于2026年最新网剧市场数据
- **平台专精**：深度理解抖音、红果算法差异
- **爆款公式**：提炼1000+爆款网剧的成功要素
- **AI增强**：结合大模型生成创新剧情和人设

### 模块2：人物工厂
生成符合平台用户喜好的人物设定

**人物属性维度**：
- 基础信息（年龄、职业、外貌）
- 性格特质（MBTI+平台偏好组合）
- 成长弧线（3集转变路径）
- 标志性特征（记忆点设计）
- 社交价值（能引发讨论的点）

### 模块3：分镜优化器
针对平台算法优化分镜节奏

**抖音分镜规则**：
- 0-3秒：视觉钩子（冲突/悬念/美色）
- 3-10秒：核心信息（谁/什么矛盾）
- 10-30秒：情节推进（第一个转折）
- 30-60秒：情绪高潮（爽点/泪点）
- 60-90秒：信息补充（背景/关系）
- 90-120秒：悬念设置（引导下集）

**红果分镜规则**：
- 0-5秒：情感引入（氛围/人物）
- 5-20秒：关系建立（人物互动）
- 20-45秒：矛盾浮现（核心冲突）
- 45-90秒：情感发展（内心戏）
- 90-150秒：情节推进（外部事件）
- 150-180秒：情感升华（主题点题）

### 模块4：台词金句库

**金句类型**：

## 🚀 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 基础使用
```python
from modules.idea_generator import IdeaGenerator
from modules.character_factory import CharacterFactory
from modules.storyboard_optimizer import StoryboardOptimizer

# 1. 生成创意
generator = IdeaGenerator()
idea = generator.generate(
    primary_genre="逆袭爽剧",
    secondary_genre="职场",
    target_platform="douyin",
    episode_count=3
)

# 2. 创建人物
factory = CharacterFactory()
characters = factory.create_ensemble(
    protagonist_traits=["坚韧", "智慧", "隐忍"],
    antagonist_traits=["傲慢", "虚伪", "势利"],
    supporting_count=3
)

# 3. 优化分镜
optimizer = StoryboardOptimizer(platform="douyin")
storyboard = optimizer.optimize(
    idea=idea,
    characters=characters,
    focus_golden_time=True,
    include_data_prediction=True
)

# 4. 导出结果
storyboard.export(format="markdown", include=["分镜", "人物", "台词", "数据预测"])
```

### 命令行使用
```bash

```

```
【30-60秒】高潮：情绪峰值/爽点
【60-75秒】回落：短暂平静/信息补充
【75-90秒】悬念：引导下集/话题讨论
```

### 红果爆款结构（180秒）
```
【0-5秒】氛围：情感基调+人物引入
【5-20秒】关系：人物互动+背景暗示
【20-45秒】矛盾：核心冲突浮现
【45-90秒】发展：内心戏+外部事件
【90-135秒】高潮：情感爆发+情节转折
【135-165秒】反思：人物成长+主题升华
【165-180秒】延续：情感余韵+系列引导】
```

### 三集系列结构
```
第一集（引入）：
  - 主角现状+核心欲望
  - 主要矛盾建立
  - 第一个挑战
  - 悬念：主角如何应对

第二集（发展）：
  - 主角行动+初步成果
  - 新挑战+盟友/敌人
  - 情感发展/内心成长
  - 悬念：危机升级

第三集（解决）：
  - 最终对决/情感高潮
  - 主角成长体现
  - 问题解决/新开始
  - 系列延续可能
```

## 🎨 视觉分镜设计

### 抖音视觉法则
1. **前3秒必须有的镜头**：
   - 特写：表情变化/关键动作
   - 快速剪辑：3个镜头内完成信息传递
   - 文字强化：关键信息大字幕

2. **节奏控制**：
   - 镜头时长：0.5-2秒，平均1秒
   - 镜头数量：90秒剧≈60-80个镜头
   - 运动镜头：≥30%，保持动感

3. **视觉记忆点**：
   - 标志性色彩：每集一个主色调
   - 重复元素：道具/动作/场景重复出现
   - 转场创意：匹配剪辑、相似形转场

### 红果视觉法则
1. **情感镜头**：
   - 长镜头：情感戏≥5秒镜头
   - 眼神戏：特写眼神传递情感
   - 空镜头：环境烘托情绪

2. **叙事节奏**：
   - 镜头时长：2-5秒，给情感留白
   - 镜头数量：180秒剧≈40-50个镜头
   - 固定镜头：≥50%，稳定感

3. **美学风格**：
   - 色调统一：每集情感色调一致
   - 构图讲究：三分法、对称、框架
   - 光影叙事：用光表达情绪变化

## 📈 数据驱动优化

### A/B测试维度
1. **标题测试**：3个版本，测试点击率
2. **封面测试**：2-3个封面，测试前3秒留存
3. **开头测试**：不同钩子设计，测试5秒留存
4. **结尾测试**：不同悬念设计，测试追剧率

### 关键指标监控
```python
关键指标 = {
    "前3秒留存率": "目标≥70%",
    "完播率": "目标≥60%",
    "平均观看时长": "目标≥85%",
    "互动率": "目标≥10%",
    "分享率": "目标≥5%",
    "追剧率": "目标≥50%",
    "粉丝转化率": "目标≥3%"
}
```

### 优化策略
1. **留存率低**：优化前3秒钩子
2. **完播率低**：优化中间节奏，增加转折
3. **互动率低**：增加话题点、争议点
4. **分享率低**：增加社交货币、情感共鸣
5. **追剧率低**：优化悬念设计、人物魅力
