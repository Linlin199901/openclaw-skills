## 平台差异

### 即梦AI
- 使用自然中文即可
- 角色描述放在 prompt 前半段
- 场景和动作放在 prompt 后半段
- 多角色用 `${角色名}${动作}` 格式分隔

### 可灵AI  
- 需要中英混合效果更好
- 面部特征用英文更稳定: `almond eyes, dark brown iris`
- 场景描述用中文
- 动作描述优先英文: `walking calmly, slight smile`

## 镜头参数速查

| 镜头 | 包含什么 | 
|------|---------|
| 特写 | 面部锚点全量 + 锚物特写 |
| 中景 | 面部简化 + 体态 + 服饰 |
| 全景 | 体态 + 服饰 + 身高参照 |
| 正面 | 面部锚点全量 |
| 侧面 | 鼻梁+耳形+下颌线+锚物侧面 |
| 背面 | 发型+发尾+锚物(如有后脑部分)+肩宽 |
