# 锚点系统详解

## 三层描述的信噪比

AI 视频模型对不同描述的响应精度有数量级差异。理解这个差异是写好角色描述的前提。

### 🔴 高信噪比：数字和比例（AI 最吃这套）

模型在训练时见过大量配了精确标签的数据（产品图、建筑图、数据可视化），所以数字和比例的描述最稳定。

```
✅ 好：
"身高168cm，7头身，肩宽38cm"
"眼距约等于一只眼的宽度"
"步幅约55cm"

❌ 差：
"身材高挑"
"五官比例很好"
```

### 🟡 中信噪比：形状和颜色（需要固定但 AI 会漂移）

形状和颜色是 AI 吃但不够稳定的层面。同一个"深棕色"在不同随机种子下可能有偏差。解决方案：**多锚点交叉锁定**——单个颜色可能漂，但"眼型+颜色+眉形+鼻型+脸型"5个锚点交叉锁定后，整体漂移概率极低。

### ❌ 零信噪比：感受词汇（AI 完全不懂）

"气质清冷"在 AI 的理解里 = 它见过的所有标注为"清冷"的图片的平均值。而哪些图片被标注为"清冷"是训练数据决定的，跟你想象的可能完全不同。更致命的是，不同 seed 下这个"平均值"的采样结果可能差异巨大。

**结论：感受词汇不仅没用，还是导致漂移的主要原因。**

## 锚点分级策略

### 一级锚点（不可变——每集 prompt 必须原样重复）

这5个面部要素一旦确定，全剧所有 prompt 必须一字不改地复制：

1. 脸型 + 细节
2. 眼型 + 虹膜颜色  
3. 眉形 + 眉色
4. 鼻梁 + 鼻头
5. 发型 + 发色

**为什么这5个**：因为这些是人脸 LFW (Labeled Faces in the Wild) 类数据集中区分个体的核心维度。AI 虽然不"知道"这些维度意味着什么，但训练数据让它对这些维度的变化最敏感。

### 二级锚点（稳定——每集都用，但允许微小调整）

- 唇色（光照会影响，给范围不定值）
- 肤色明度（场景光线下自然变化）
- 核心锚物（必须出现，但角度可调）

### 三级锚点（浮动——根据剧情需要变化）

- 表情（剧情驱动）
- 服饰（场景驱动，但配色DNA和材质不变）
- 发型微调（战斗后凌乱、睡觉后散开等，但颜色和长度锁定）

## 多角色同框的锚点检查

当两个角色同时出现在画面中时，额外检查：

1. **身高差是否正确**：参照身高对照表
2. **锚物是否穿帮**：两个角色的锚物有没有被遮挡或重叠
3. **配色是否冲突**：有没有两个角色穿同色系导致难以区分
4. **体型对比**：肩宽/骨架差异是否体现
