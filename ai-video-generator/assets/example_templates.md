## 使用指南

### 1. 选择基础模板
根据内容类型选择最接近的模板作为起点。

### 2. 替换关键元素
- 替换`[场景描述]`为具体场景
- 替换`[角色引入]`为具体角色
- 替换`[动作序列]`为具体动作
- 替换`[对话交互]`为具体台词

### 3. 添加平台优化
根据目标平台添加相应的优化标签。

### 4. 调整情感强度
根据剧情需要调整情感元素的密度和强度。

### 5. 测试和迭代
生成后测试效果，根据反馈调整优化。

### 6. 保存模板
将成功的提示词保存为新的模板，建立个人模板库。

## 快速提示词生成公式

```
1. 确定核心：主角 + 动作 + 冲突
2. 添加场景：地点 + 时间 + 氛围
3. 设计镜头：运镜 + 角度 + 运动
4. 配置音频：对话 + 音效 + 音乐
5. 增强特效：光效 + 粒子 + 转场
6. 平台优化：标签 + 节奏 + 时长
```
