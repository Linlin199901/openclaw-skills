# 音视频一体生成示例 - 《BUG修仙系统》

## 示例场景：AI系统BUG爆发

### 原始剧本
```
场景：现代办公室，深夜
角色：陈代码在调试豆包AI系统
动作：陈代码快速敲击键盘，突然系统蓝屏
对话：陈代码："怎么回事？系统崩溃了？"
        豆包AI："错误！维度穿越BUG激活！"
特效：屏幕闪烁红光，代码乱流
音频：系统警报声，穿越音效
```

## 音频元素分解

### 1. 人物对白设计
```
陈代码对话：
- 声音属性：25岁男性，沙哑疲惫
- 情绪变化：惊恐 → 难以置信
- 语速节奏：正常 → 颤抖缓慢

豆包AI系统音：
- 声音属性：自信电子音
- 情绪变化：自信 → 警报 → 恢复自信
- 音调变化：正常 → 高亢警报 → 恢复正常
```

### 2. 环境音分层
```
办公室环境：
- 主层：空调低频运转声
- 次层：远处街道车声
- 点缀：深夜安静氛围

穿越过程：
- 现实音逐渐失真
- 加入电子干扰
- 最终完全消失

修仙界环境：
- 主层：山风呼啸
- 次层：瀑布轰鸣
- 点缀：鸟鸣、灵气波动
```

### 3. 音效同步点
```
精确同步：
1. 键盘敲击停止 → 键盘声停止
2. 屏幕蓝屏 → 系统警报声
3. 场景扭曲 → 空间撕裂声
4. 身体透明 → 代码流动音
5. 落地 → 撞击声+尘土声
```

### 4. 音乐情绪曲线
```
情绪变化：
1. 开头：轻微紧张（调试BUG）
2. 发展：紧张加剧（系统崩溃）
3. 高潮：极度紧张（穿越过程）
4. 转折：神秘好奇（到达修仙界）
5. 结尾：略带幽默（AI自信恢复）

乐器变化：
现代电子音 → 古风乐器融合
```

## 质量控制检查点

### 音频同步检查
- [ ] 所有动作都有对应音效
- [ ] 音效出现时间精确
- [ ] 对话节奏自然
- [ ] 音乐进出平滑

### 音量平衡检查
- [ ] 对话清晰可辨
- [ ] 音效不掩盖对话
- [ ] 环境音适当
- [ ] 音乐作为情绪衬托

### 情绪一致性检查
- [ ] 音频情绪与画面情绪匹配
- [ ] 角色声音与情绪一致
- [ ] 音乐情绪支持剧情
- [ ] 环境音增强氛围

### 空间真实感检查
- [ ] 环境音符合场景
- [ ] 声音有距离感
- [ ] 混响效果适当
- [ ] 方向感清晰

## 调整建议

### 如果对话不清晰
1. 添加`[音频优化：对话音量优先]`
2. 降低环境音和音乐音量描述
3. 确保对话在安静时刻出现

### 如果音效不同步
1. 添加精确时间描述：`[动作后0.3秒] + [音效：...]`
2. 使用平台同步标签：`[即梦优化：帧级同步]`
3. 简化复杂动作的音效描述

### 如果音乐情绪不匹配
1. 明确指定音乐类型：`[音乐：紧张电子乐]`
2. 添加情绪标签：`[音乐情绪：悬疑紧张]`
3. 使用平台智能匹配：`[可灵优化：自动情绪匹配]`
