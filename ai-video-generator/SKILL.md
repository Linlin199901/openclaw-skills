# AI视频生成提示词创作技能

本技能帮助你将文本内容（剧本、故事、场景描述）转化为结构化、高质量的AI视频生成提示词，适用于即梦AI、可灵AI等主流视频生成平台。

## 核心原则

### 提示词结构公式（音视频一体）
```
提示词 = 场景（场景描述）+ 主体（主体描述）+ 运动（运动描述）+ 音频（对话/唱歌/音效/纯音乐/环境音）+ 其他（风格/情感/镜头）
```

### 现代AI视频生成平台音频能力
当前主流AI视频生成平台（即梦AI、可灵AI等）已全面支持音视频一体生成，包括：
1. **人物对白**：支持多角色对话，可指定声音属性、情绪、语速
2. **环境音效**：支持背景环境音、自然音、机械音等
3. **音乐伴奏**：支持背景音乐、主题音乐、情绪音乐
4. **音效同步**：支持动作音效与画面精确同步
5. **语音合成**：支持文本转语音，可调节音色、语调、情感

### 音频元素规范（现代AI视频生成平台）

#### 1. 人物对白格式
- **单角色**：`[陈代码，25岁男性，声音略带疲惫]："这个BUG太奇怪了。"`
- **多角色对话**：`[苏清雪，清冷女声]："你是何人？" [陈代码，结巴紧张]："我...我是程序员..."`
- **声音属性**：年龄、性别、音色（清脆/沙哑/低沉）、语速、情绪
- **时序控制**：`[停顿2秒]`、`[紧接着]`、`[同时]`

#### 2. 环境音格式
- **背景环境**：`[环境音：山风呼啸 + 远处鸟鸣 + 瀑布声]`
- **空间混响**：`[空旷山洞回声]`、`[狭小室内混响]`
- **时间变化**：`[夜晚虫鸣渐强]`、`[雨声由小变大]`

#### 3. 动作音效格式
- **同步音效**：`[陈代码快速敲击键盘] + [键盘敲击声密集响起]`
- **材质音**：`[玻璃破碎声清脆]`、`[金属撞击声沉闷]`
- **拟声词**：`[砰！关门声]`、`[咔嚓！树枝断裂]`

#### 4. 音乐伴奏格式
- **背景音乐**：`[背景音乐：舒缓钢琴曲，忧郁情绪]`
- **主题音乐**：`[主题音乐：史诗交响乐，高潮部分]`
- **情绪音乐**：`[紧张悬疑音乐渐起]`、`[浪漫温柔音乐]`

#### 5. 特殊音效格式
- **魔法/科技音**：`[灵气波动音效]`、`[代码流动电子音]`
- **穿越/特效音**：`[维度穿越嗡鸣声]`、`[时间暂停滴答声]`
- **系统提示音**：`[AI系统电子提示音]`、`[错误警报声]`

#### 6. 音频混合规则
- **主次分明**：对话为主时，环境音降低音量
- **时序精确**：音效与动作帧精确同步
- **情绪匹配**：音乐情绪与画面情绪一致
- **空间真实**：根据场景调整声音空间感

## 工作流程

### 步骤1：分析输入内容
1. 识别场景类型（室内/室外/幻想/现实）
2. 识别主要角色和数量
3. 识别关键动作和运动
4. 识别音频需求（对话/音乐/音效）

### 步骤2：构建基础提示词
1. 按照结构公式组织内容
2. 为每个角色分配唯一标签
3. 为对话添加声音属性标签
4. 为动作添加程度副词

### 步骤3：添加镜头语言
从[镜头词典](references/lens_dictionary.md)中选择合适的镜头：
- **运镜**：切换、平移、推轨、环形跟踪、跟随、固定、聚焦、手持
- **程度副词**：快速、大幅度、高频率、剧烈、缓缓

> 🎥 **完整的17种运镜体系请参考**：[运镜语言参考库](../references/camera-movement-reference.md)

### 运镜提示词写作5条心法

> 来源：WaytoAGI · 小歪的AI工具箱

#### 心法1：运镜指令放在最前面
AI对提示词开头的权重更高。先写运镜类型，再描述场景。
- ✅ `环绕镜头，画面围绕[主体]做360度旋转。她...`
- ❌ 把运镜埋在大段描述中间

#### 心法2：写清"起点"和"终点"  
不要只写"推镜头"，要写"从全景推近至眼部特写"。起点终点越清晰，AI越知道怎么"走"。
- ✅ `推镜头，画面从全景向前推进至眼部大特写`
- ❌ `推镜头，拍他的脸`

#### 心法3：给一个速度词
速度定情绪：
| 速度 | 适用情绪 |
|------|----------|
| 缓慢 | 深情、优雅、悬疑、庄严 |
| 匀速 | 叙事、展示、跟随 |
| 快速/极速 | 紧张、冲击、惊吓、节奏 |
| 由慢到快 | 情绪升温、高潮推进 |

#### 心法4：运镜 + 情绪关键词 = 黄金搭档
单独的运镜是技术指令，加上情绪才是创作指令。
- ✅ `缓慢推镜头，沉重压抑的氛围`
- ✅ `环绕镜头，史诗仪式感`

#### 心法5：一条提示词最多1-2种运镜
15秒短视频1-2种运镜足够。复杂镜头拆成多条分别生成再拼接。

### 步骤4：优化提示词
1. 检查角色标签一致性
2. 验证时序逻辑
3. 添加情感和风格标签
4. 确保音频元素完整

## 快速参考

### 角色命名规则
- **必须唯一**：`[角色A: 黑衣特工]` 和 `[角色B: 女助手]`
- **避免代词**：不要使用"他"、"她"等代词
- **始终如一**：在整个提示词中使用相同的角色标签

### 视觉锚定技巧
- **动作绑定台词**：先描述动作，后接台词
- **示例**：黑衣特工猛地拍了一下桌子。`[黑衣特工, 愤怒地喊]："真相在哪？"`

### 音频细节规范
- **为每个角色赋予独特音色**：`[黑衣特工, 声音沙哑、低沉]："别动。"`
- **避免模糊描述**：不要使用`[男人]说... [女人]说...`

### 时序控制方法
- **使用连接词**：`紧接着`、`随后`、`同时`
- **强约束示例**：`[黑衣特工]："为什么？` 这时候说话人切换 `[女助手]："因为时间到了。"`

## 常见问题

### Q: 如何确保角色视觉一致性？
A: 为每个角色创建详细的视觉描述档案，包括：
- 服装特征
- 发型和发色
- 面部特征
- 标志性动作
- 声音特征

### Q: 如何处理复杂的多角色对话？
A: 使用以下结构：
1. 明确标注每个说话者
2. 添加时序连接词
3. 为每个角色分配独特音色
4. 绑定动作到具体角色

### Q: 如何优化生成效果？
A: 实验以下技巧：
1. 调整镜头语言密度
2. 平衡视觉和音频元素
3. 添加平台特定的优化标签
4. 使用A/B测试对比不同提示词
