# 网剧案例 - AI视频生成提示词示例

## 《BUG修仙系统》专用示例

### 示例1：开场场景 - 程序员穿越

**场景描述**：
2026年，字节跳动办公室，陈代码（主角）正在调试豆包AI系统，突然系统出现BUG，将他吸入修仙世界。

**完整提示词**：
```
[现代办公室场景] + [陈代码，25岁AI工程师，穿着程序员T恤，黑眼圈明显]坐在电脑前[快速敲击键盘] + [镜头特写]电脑屏幕上[豆包AI界面闪烁红色错误代码] + [系统提示音："警告！维度穿越BUG激活！"] + [镜头剧烈晃动]办公室场景[逐渐扭曲变形] + [数字雨特效]覆盖整个画面 + [镜头360度旋转]陈代码[惊恐地抓住桌子] + [穿越音效：嗡鸣声渐强] + [突然切换]至[古代修仙世界场景] + [陈代码]从空中[缓缓降落]在[云雾缭绕的山巅] + [背景音乐：史诗穿越混合电子音]
```

**音频细节**：
- `[系统AI，机械电子音]："维度穿越BUG已激活，准备传送..."`
- `[陈代码，惊恐颤抖]："等等！这是什么BUG？"`
- `[穿越音效：空间撕裂声 + 电子嗡鸣 + 风声呼啸]`
- `[落地音效：轻微撞击 + 尘土飞扬]`
- `[环境音：山风呼啸 + 远处鸟鸣 + 瀑布声]`

## 实用技巧

### 1. 情绪曲线设计
- **开头**：高能量吸引（喜剧/惊奇）
- **发展**：情感建立（角色互动）
- **高潮**：冲突爆发（动作/情感）
- **结尾**：悬念留白（期待下集）

### 2. 节奏控制
- **抖音**：每3秒一个视觉冲击
- **B站**：每30秒情绪/笑点变化
- **红果**：每5秒情感推进

### 3. 平台适配
- **竖屏**：中心构图，上下留白
- **横屏**：宽幅场景，细节丰富
- **时长**：匹配平台最佳时长（抖音60s，B站3-5min）
