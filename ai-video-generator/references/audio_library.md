## 实用模板

### 对话模板
```
[角色A，声音特质+情绪]："对话内容" [连接词] [角色B，声音特质+情绪]："回应内容"
```

### 音效模板
```
[物体：类型] [动作：描述] + [拟声词：专业词汇] + [材质状态：形容词]
```

### 环境音模板
```
[场景类型] + [声音元素1] + [声音元素2] + [空间感描述]
```

### 音乐模板
```
[乐器类型]演奏的 + [音乐流派] + [情绪形容词] + [节奏描述]
```

使用这些音频元素可以让视频的音效更加专业和生动。
