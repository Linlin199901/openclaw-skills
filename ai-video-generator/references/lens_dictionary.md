# 镜头词典 - AI视频生成专用

## 运镜类型

### 1. 基础运镜
- **切换**：`镜头切换`
- **平移**：`镜头向上/下/左/右移动`
- **推轨**：`镜头拉近/拉远`
- **环形跟踪**：`镜头环绕`
- **航拍**：`航拍镜头`
- **广角**：`广角镜头`
- **旋转**：`镜头360度旋转`
- **跟随**：`镜头跟随`
- **固定**：`固定镜头`、`镜头静止不动`
- **聚焦**：`镜头特写`
- **手持**：`镜头晃动`、`镜头抖动`、`手持拍摄`、`动态不稳定`

### 2. 程度副词
用于突出主体动作频率与强度：
- **速度**：`快速`、`缓慢`、`匀速`、`突然`
- **幅度**：`大幅度`、`轻微`、`剧烈`、`柔和`
- **频率**：`高频率`、`低频`、`间歇性`、`持续`
- **强度**：`强烈`、`微弱`、`猛烈`、`轻柔`

## 镜头组合模式

### 1. 叙事镜头序列
```
镜头1：广角镜头 + 场景全景
镜头2：镜头拉近 + 主体特写
镜头3：镜头环绕 + 主体运动
镜头4：镜头切换 + 新场景
```

### 2. 情感表达镜头
- **紧张**：`快速切换` + `手持抖动` + `特写聚焦`
- **浪漫**：`缓慢平移` + `柔和聚焦` + `镜头环绕`
- **动作**：`剧烈晃动` + `快速跟随` + `多角度切换`
- **神秘**：`缓慢拉近` + `低角度` + `阴影效果`

### 3. 对话场景镜头
```
镜头A：特写角色A说话
镜头B：切换至角色B反应
镜头C：双人镜头对话
镜头D：过肩镜头交流
```

## 平台优化建议

### 抖音/短视频平台
- **前3秒钩子**：`剧烈晃动` + `快速切换` + `高饱和度`
- **节奏匹配**：`镜头切换频率`匹配背景音乐节奏
- **竖屏优化**：`垂直构图` + `中心聚焦`

### B站/中视频平台
- **玩梗镜头**：`突然特写` + `夸张运镜` + `特效转场`
- **知识区风格**：`稳定推轨` + `文字标注` + `分屏展示`
- **每30秒情绪波动**：定期改变镜头语言强度

### 红果/情感向平台
- **前5秒情感引入**：`缓慢拉近` + `柔光效果` + `情感音乐`
- **情感累积**：`镜头逐渐靠近` + `色调渐变`
- **高潮释放**：`快速切换` + `多角度` + `动态效果`

## 专业技巧

### 1. 深度暗示
- **前景模糊**：`浅景深` + `主体清晰`
- **层次感**：`多层构图` + `渐进聚焦`
- **空间感**：`广角拉伸` + `透视效果`

### 2. 运动匹配
- **主体运动**：`镜头跟随速度`匹配`主体移动速度`
- **情感运动**：`镜头晃动强度`匹配`情感强度`
- **节奏运动**：`切换频率`匹配`背景节奏`

### 3. 转场技巧
- **硬切**：`直接切换`（用于节奏变化）
- **淡入淡出**：`渐变切换`（用于场景过渡）
- **匹配剪辑**：`动作连贯切换`（用于时间跳跃）
- **跳切**：`突然跳跃`（用于喜剧效果）
